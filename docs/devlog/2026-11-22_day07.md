## 1. 1단계 관리자 시스템 & DB 이중 보안 (`b0281e6`, `95d1ef6`)
- **DB 마이그레이션 ([admin_migration.sql](file:///c:/00_Project/02_Keyniverse/supabase/admin_migration.sql), [admin_author_ids_rpc.sql](file:///c:/00_Project/02_Keyniverse/supabase/admin_author_ids_rpc.sql)):**
  - `profiles.role` (`'user' | 'admin'`), `profiles.banned_until` 추가 및 `is_admin()`, `is_banned()` 판별 함수 구축.
  - **`protect_profile_sensitive_columns()` 트리거:** 일반 유저가 API로 `role`·`banned_until`을 셀프 변조하는 취약점을 DB 레벨에서 원천 차단.
  - **RLS 보강:** 공지사항(`notice`)은 관리자만 작성 가능, 정지 계정은 DB 레벨에서 글·댓글 작성 차단, 관리자는 모든 게시글·댓글 삭제 및 신고 처리 가능.
  - 전용 RPC `admin_resolve_report`(원본 삭제 + 동일 대상 미처리 신고 일괄 처리), `admin_set_user_ban`(1/7/30일/영구/해제), `get_admin_author_ids`(개인정보 노출 없이 관리자 UUID만 반환) 구현.
- **관리자 콘솔 ([page.tsx](file:///c:/00_Project/02_Keyniverse/src/app/admin/page.tsx), [AdminDashboardClient.tsx](file:///c:/00_Project/02_Keyniverse/src/components/admin/AdminDashboardClient.tsx)):**
  - 서버 컴포넌트에서 `role === 'admin'` 선검증 → 비관리자 접근 시 **`404 Not Found`** 반환 (`robots.ts`에도 `/admin` 제외 추가).
  - 상단 KPI 4카드(`총 회원`, `총 게시글`, `미처리 신고`, `활동 정지`) + **신고 처리함** + **회원 관리** 구현.
- **현장 즉시 처리 & 관리자 닉네임 색상:**
  - 관리자 로그인 시 타인 게시글·댓글 즉시 `[삭제]` 및 5개 게시판별(`전체`·`자유`·`빌드`·`투표`·`특가`) `[공지사항]` 작성·수정(`notice_scope` DB 동기화) 가능.
  - 별도 배지 추가 대신 관리자 작성자 닉네임을 **포레스트 세이지(`#6B9080`)** 색상으로 구분(목록·상세·댓글 통일), 닉네임 변경 직후 커뮤니티 캐시 즉시 동기화 추가.

## 2. 헤더 `BETA` 배지 · 자간 축소 · 원형 프로필 팝오버 (`b0281e6`, `4c6b19d`)
- [TopNav.tsx](file:///c:/00_Project/02_Keyniverse/src/components/layout/TopNav.tsx), [Footer.tsx](file:///c:/00_Project/02_Keyniverse/src/components/layout/Footer.tsx), [opengraph-image.tsx](file:///c:/00_Project/02_Keyniverse/src/app/opengraph-image.tsx): `KEYNIVERSE` 자간을 `tracking-tight`로 좁히고 헤더·푸터에 세이지 틴트 **`BETA`** 칩 부착.
- `< 400px` 초소형 모바일에서 헤더 가로폭 초과로 화면이 축소되던 문제를 해결하기 위해, 기존 우측 유저 영역(약 `156px`)을 **`36px` 원형 `User` 아이콘 버튼 + 우측 정렬 드롭다운 팝오버**로 전환.
  - 팝오버 구성: 상단 요약(닉네임 · 실시간 보유 포인트 `P`, 이메일 제외) + `마이페이지` · (`관리자 대시보드`) · `로그아웃`.
  - 햄버거 메뉴와 상호 배타적 열림/닫힘, `pointerdown` 외부 탭 감지, `Esc` 키 닫기, 닫힘 시 `pointer-events-none` / `tabIndex={-1}` 적용.
