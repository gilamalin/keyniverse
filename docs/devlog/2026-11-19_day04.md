## 1. 스펙 도감(`/specs`) 모듈화 리팩토링 및 반응형 그리드 개선

### 1-1. 카테고리 확장·백엔드 연동 대비 모듈 분리 (`src/components/specs/`)
- 단일 거대 파일이었던 `SpecsCatalog.tsx`를 역할별로 분리하여 향후 기성품 키보드·키캡 등 신규 카테고리 추가와 서버 데이터(`initialSwitches`, `initialMice`) 주입이 용이한 구조로 리팩토링:
  - `CatalogSharedUI.tsx`: 공용 필터 사이드바 Shell, 범위 슬라이더, 검색/정렬 툴바, 빈 결과 상태 UI
  - `SwitchCatalogView.tsx` / `MouseCatalogView.tsx`: 각 카테고리 전용 필터 상태, 정렬 로직, 스펙 카드 렌더링
  - `SpecsCatalog.tsx`: URL 쿼리 동기화, 카테고리 탭 전환, 비교함·상세 모달 통합 관리 Shell
- **자동 열 계산 그리드 적용:** `grid-cols-1 md:grid-cols-2 xl:grid-cols-3` 대신 **`grid-cols-[repeat(auto-fill,minmax(275px,1fr))]`**를 적용하여 `760px` 전후 및 사이드바 토글 구간에서도 카드가 가로로 길게 늘어지지 않고 균형 잡힌 2~3열을 유지하도록 개선.

### 1-2. 제품 상세 모달(`SpecDetailModal.tsx`) · 비교 모달(`SpecCompareModal.tsx`) 개편
- **한줄평 기능 & 평가 삭제 경로 단일화 (`src/lib/spec-verification.ts`, `src/data/specs-data.ts`):**
  - `StoredSwitchVote` / `StoredMouseVote`에 선택 입력 `oneLineReview`(최대 80자)를 추가하고, 초기 더미 로그 26건을 실제 제품 특성에 맞는 한국어 한줄평으로 전면 교체.
  - 등록 직후 입력란 자동 초기화, 평가 폼 하단 `[수정]` 옆에 단일 **`[삭제]`** 버튼을 배치해 한줄평 작성 여부와 무관하게 평점·지표·한줄평을 한 번에 삭제할 수 있도록 단순화.
- **로그인 + 테스트 통과 이중 인증 게이트:** 1계정 1평가 원칙에 맞춰 `Google 로그인`과 `테스트 무결점 통과` 두 조건을 모두 충족해야 평가 폼이 활성화되도록 통합.
- **유저 지표 컴팩트 타일화 & 모바일 넘침 방지:**
  - 긴 스펙 값(`SpecRow`)의 `whitespace-nowrap`을 제거하고 `min-w-0 break-words`로 수정, 스펙 테이블 2열 전환 기준을 `500px`로 하향하고 모달 폭을 `max-w-2xl`로 조정.
  - 유저 지표(`피치`, `그립`, `손 크기`)를 3칸/4칸 컴팩트 타일 그리드(`VoteRatioTiles`)로 압축.
- **스펙 비교 모달 `sticky` 항목 열 & 플로팅 바 최적화:**
  - `<table>`의 `overflow-hidden`·`border-collapse`를 제거하고 `border-separate border-spacing-0` + 전용 `overflow-x-auto` 래퍼를 적용해 모바일 좌우 스크롤 시 좌측 `항목` 열이 안정적으로 고정되도록 수정.
  - 하단 플로팅 비교함 바의 제품 칩을 모바일 1줄 가로 스크롤로 정리하고, 연결 방식 표기를 `'유무선'` / `'유선'`으로 간소화.

## 2. 커뮤니티 · 네비게이션 · 로그인 UI 미니멀화 및 반응형 개선

- **게시글 내 장비 링크 인플레이스 스펙 모달 팝업 (`PostDetailModal.tsx`):**
  - `[빌드/셋업]`, `[투표]`, `[자유 게시판]`, `[특가/드랍]` 게시글에서 제품명 클릭 시 `/specs` 페이지로 강제 이동하지 않고 그 자리에서 `<SpecDetailModal />`이 팝업(`ESC` / `X` / 바깥 클릭 닫힘)되도록 개선.
- **상단 헤더 팝오버 & 브레이크포인트 최적화 (`TopNav.tsx`, `AuthModal.tsx`):**
  - 데스크톱 메뉴 전환 기준을 `1024px(lg)` → **`880px`(`min-[880px]`)**으로 낮추고, `1024px` 미만에서는 닉네임 말줄임(`max-w-[72px]`) + 로그아웃 아이콘화로 화면 이탈 방지.
  - `880px` 미만에서도 `로그인` 버튼(로그인 시 닉네임·로그아웃)을 햄버거 버튼 왼쪽에 상시 노출하고, 햄버거 메뉴를 화면 풀폭 드로어 대신 **`150ms ease-out` 우측 고정폭 팝오버(`w-56`)**로 개편.
  - 로그인 모달에서 테스트용 닉네임 입력란·보안 장문 설명을 제거하고 **`Google 계정으로 계속하기`** 단일 버튼 + 약관 동의 1줄로 단순화.
- **커뮤니티 사이드바 중간 폭 반응형 (`CommunityBoard.tsx`):**
  - `640px~1023px` 구간에서 `인기글 TOP 5`와 `금주의 핫 VS 매치업`을 상단 2열로, `SPONSORED AD`를 하단 가로형 배너(`sm:col-span-2`)로 배치해 빈 여백 해소.
  - 댓글/답글 입력창을 통합 박스 + `resize-none` 자동 높이 조절로 정리하고, 빈 값일 때 `[등록]`/`[수정 완료]` 버튼 비활성화(`disabled`) 적용.
- **전 페이지 소제목 명사형 1줄 통일:**
  - 커뮤니티(`생각을 자유롭게 나누는 공간`), 스펙 도감(`하드웨어 스펙 조건별 검색 · 비교`), 키보드 테스트(`키 입력 · 동시입력 · 채터링 실시간 진단`), 마우스 테스트(`폴링레이트 · 5버튼 더블클릭 실시간 진단`).

## 3. 키보드·마우스 테스트 페이지 레이아웃 및 사용성 개선

- **키보드 테스트 (`KeyboardTester.tsx`):**
  - `[초기화]` 버튼을 페이지 상단 우측으로 올려 마우스 테스트와 통일하고, `입력 중 · 정상 확인 · 채터링 경고` 범례를 가상 키보드 덱 바로 위로 이동해 시선 동선 단축.
  - 키보드 덱에 CSS Container Query(`[container-type:inline-size]`)를 적용해 104키(`(100cqw - 80px) / 22.9`)와 87키(`(100cqw - 68px) / 18.45`)가 창 너비에 맞춰 자동 축소되도록 수정(데스크톱 좌우 스크롤바 제거).
- **마우스 테스트 (`MouseTester.tsx`):**
  - 5버튼 카드의 하단 테두리를 전 상태 `border-b-2` + 상단 행 `h-4`로 고정해 클릭 시 카드 꿀렁임(`1px` 높이 변화) 완전 제거.
  - 클릭 간격 표기에서 `'간격:'` 라벨을 제거하고 `1000ms` 이상은 `1.2s`처럼 초 단위로 자동 축약(`whitespace-nowrap`)해 3~5자리 숫자에서도 두 줄 밀림 방지.
  - 우측 클릭 기록 박스를 데스크톱에서 좌측 컬럼 높이에 100% 종속(`lg:relative` + `lg:absolute lg:inset-0`)시켜 스크롤바 발생 시 전체 박스가 하단으로 팽창하는 현상 해결.

## 4. 프론트엔드 필수 기능 완성 및 중첩 모달 버그 수정

1. **커스텀 `404` 페이지 (`src/app/not-found.tsx`):** 다크 매트 톤의 `404` 안내 화면 및 홈 이동 버튼 구현.
2. **활동 포인트 & 신고 경량 스토어 (`src/lib/activity-store.ts`):**
   - 양수(적립)와 음수(소모)를 모두 지원하는 `delta` 기반 `PointLogEntry` 설계로 추후 백엔드 연동 후 포인트 소모처 확장 대비(`글 작성 +10P`, `댓글/답글 +3P`, `스펙 평가 +5P`).
3. **유저 프로필 모달 (`src/components/community/UserProfileModal.tsx`):**
   - 게시글·댓글 작성자 닉네임 클릭 시 팝업(`max-w-[356px]`). 활동 포인트, 요약 2칸(`게시글` · `댓글`), 최근 작성 글 목록, 본인 프로필일 경우 `[마이페이지 →]` 버튼 제공.
4. **마이페이지 (`src/app/mypage/page.tsx`, `src/components/mypage/MyPageClient.tsx`):**
   - 헤더 우상단 내 닉네임 클릭 시 이동. 인라인 `닉네임 변경`(2~6자 검증), 연결된 Google 이메일, 보유 포인트(`min-[460px]:flex-row`), 4개 탭(`작성 글 · 작성 댓글 · 스펙 평가 · 포인트 내역`), 하단 **`회원 탈퇴` + 확인 모달** 구현.
5. **게시글·댓글·답글 신고 모달 (`src/components/community/ReportModal.tsx`):**
   - 타인의 게시글·댓글·답글 우측에 매트 코랄(`#E06C75`) **사이렌(`Siren`) 아이콘** 신고 버튼 통일 배치, 5개 사유 선택·중복 신고 차단 구현.
6. **중첩 모달 z-index & 스크롤 영구 잠김 버그 원천 차단 (`src/lib/body-scroll-lock.ts`):**
   - `AuthModal` z-index를 `z-[60]`으로 상향하고, 5개 모달 전체에 참조 카운트 기반 `acquireBodyScrollLock()`을 적용해 스펙 모달 위에서 로그인 모달을 여닫아도 스크롤이 영구 잠기지 않도록 해결.
   - `PostDetailModal` 하단의 `<SpecDetailModal>` / `<ReportModal>` 중복 키(`"closed"`)를 `"spec-closed"` / `"report-closed"`로 분리해 React 콘솔 에러 제거.
