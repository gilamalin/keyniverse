## 1. 실서비스 버그 수정 (`c542b4e`)

### 1-1. 모바일 스펙 도감 슬라이더 트랙·핸들 미표시 해결
- **원인:** [slider.tsx](file:///c:/00_Project/02_Keyniverse/src/components/ui/slider.tsx)의 `@base-ui/react/slider`에 설정된 `thumbAlignment="edge"`가 초기에 `hidden`(`display: none`) 상태인 모바일 필터 영역의 가로폭을 `0`으로 측정해, 내부에서 핸들에 `visibility: hidden`을 걸던 현상.
- **해결:** `thumbAlignment="edge"`를 제거(기본 `center`, 순수 CSS `%` 배치)하고 [CatalogSharedUI.tsx](file:///c:/00_Project/02_Keyniverse/src/components/specs/CatalogSharedUI.tsx) 슬라이더 래퍼 좌우 여백을 `px-2`로 조정.

### 1-2. 조회수 포함 Supabase 지연 실행(Lazy Thenable) 버그 8곳 일괄 수정
- **원인:** `@supabase/supabase-js`의 `PostgrestBuilder`는 `.then()` 또는 `await`를 호출해야만 실제 HTTP 요청이 전송되는데, `void supabase.rpc(...)` 형태로 호출해 요청이 서버로 전송되지 않던 문제.
- **해결:** [community-store.ts](file:///c:/00_Project/02_Keyniverse/src/lib/community-store.ts) 6곳(`incrementPostView`, `toggleDealPostStatus`, `updateCommunityComment`, `deleteCommunityComment`, `updateCommunityPost`, `deleteCommunityPost`) 및 [spec-verification.ts](file:///c:/00_Project/02_Keyniverse/src/lib/spec-verification.ts) 2곳(`saveStoredVote`, `deleteStoredVote`)을 모두 `async` IIFE + `await` + 에러 로깅 구조로 수정.

## 2. 조회수 중복 방지 & 새로고침 스켈레톤 UX (`bf19e5f`)
- **작성자 본인 재클릭 중복 방지:** 새 글 작성 시 조회수 `1`로 시작하면서 즉시 `markPostViewedInSession()`에 등록해 같은 세션 내 본인 재클릭 시 `2`로 오르지 않도록 정비.
- **레이아웃 튐·깜빡임 방지 스켈레톤:**
  - `community-store.ts`에 `isCommunitySynced()`를 추가해 `/?post=...` 새로고침 시 DB 응답 전까지 상단 대제목 헤더가 번쩍이거나 하단 목록이 위로 튀지 않도록 매트 다크 스켈레톤 카드 배치.
  - `auth-store.ts`에 `isAuthSessionResolved()`를 추가해 `/mypage` 새로고침 시 세션 복원 전 "로그인이 필요합니다" 카드가 깜빡이지 않도록 마이페이지 스켈레톤 배치.

## 4. 스펙 도감 필터 스크롤 UX 고도화 (`26028dd`, `6322c89`)
