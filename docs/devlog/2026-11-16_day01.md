### 1-2. 키보드 채터링 & 동시입력(NKRO) 정밀 테스터 (`src/components/keyboard/KeyboardTester.tsx`, `src/lib/keyboard-layout.ts`)
- **레이아웃 전환:** 104키 풀배열(Full-size) 및 87키 텐키리스(TKL) 전환 지원 + 우상단 하드웨어 Lock 상태 표시등(`NUM`, `CAPS`, `SCR`).
- **고정밀 채터링 검출 엔진:**
  - `performance.now()`(sub-ms 정밀도) 기반으로 각 물리 키(`e.code`)의 **`KeyUp → 다음 KeyDown` 재입력 간격(ms)**을 측정하여, 단일 키 연타 테스트와 일반 타자 입력 중 발생하는 스위치 접점 채터링을 모두 감지.
  - 키를 길게 누르고 있을 때 발생하는 OS 자동 반복 입력(`e.repeat === true`)은 채터링 판정에서 제외.
  - 채터링 임계값 슬라이더(`5ms ~ 50ms`, 기본 `20ms`) 실시간 조절 지원.
- **한국어 Windows 환경 및 특수키 예외 처리:**
  - 한국어 IME 환경에서 우측 한/영 키(`Lang1`/`HangulMode` → `AltRight`) 및 한자 키(`Lang2`/`HanjaMode` → `ControlRight`) 자동 매핑 및 `keyup` 누락 대비 `150ms` 자동 해제 타이머 적용.
  - Windows OS가 `keydown`을 가로채고 `keyup`만 전달하는 `PrintScreen` 키에 대해 `90ms` 합성 탭(Tap) 처리.
- **편의 잠금 기능:**
  - **`단축키 잠금 (F1~F12·Tab)`:** 브라우저 기본 동작(`e.preventDefault()`)으로 잠글 수 있는 `F1~F12`, `Tab`, `Alt`, `Space`, 방향키 스크롤, 우클릭 메뉴 키를 차단 (OS 드라이버가 제어하여 브라우저에서 잠글 수 없는 `ScrLk` 표기는 제외).
  - **`전체화면 Win키 잠금`:** Fullscreen API + `navigator.keyboard.lock()`을 통해 테스트 중 Windows 시작 메뉴 호출 방지.
- **실시간 히스토리 로그 테이블:** `table-fixed` 고정 폭 컬럼 및 `[전체 보기 | 채터링 경고만]` 필터로 열 흔들림 없이 실시간 타건 로그 출력.

### 1-3. 마우스 8K 폴링레이트 & 5버튼 더블클릭 정밀 테스터 (`src/components/mouse/MouseTester.tsx`)
- **8,000Hz 원시 이벤트 추출 및 연산:**
  - `PointerEvent.getCoalescedEvents()`로 브라우저 프레임에 묶인 원시 마우스 이동 이벤트를 분해하고, 슬라이딩 프레임 윈도우 구간의 실제 시간 스팬 대비 이벤트 수로 `Live Hz`, `Peak Hz`, `Avg Hz`(가감속 구간 노이즈를 배제하기 위해 `peakHz * 0.6` 이상 유효 구간만 평균 산출) 계산.
- **하이브리드 8K 트래킹 박스 & 실시간 캔버스 그래프:**
  - 마우스를 올리는 즉시 측정되는 호버 모드 + 클릭 시 화면 밖 이탈을 막아주는 포인터 잠금(`requestPointerLock({ unadjustedMovement: true })`) 하이브리드 지원.
  - `requestAnimationFrame` 기반 60FPS+ 고해상도(DPR 스케일링) 파형 그래프 및 레이더 궤적 렌더링 (React 상태 동기화는 20Hz로 스로틀링하여 8K 이벤트 병목 원천 차단).
- **5버튼 스위치 더블클릭(채터링) 진단기:**
  - `좌클릭(LMB)`, `우클릭(RMB)`, `휠클릭(MMB)`, `사이드 뒤로(M4)`, `사이드 앞으로(M5)` 5개 버튼의 `MouseUp → MouseDown` 간격 측정 (`5ms ~ 80ms`, 기본 `20ms`).
  - 테스트 영역 내 우클릭 컨텍스트 메뉴, 휠 클릭 자동 스크롤, 마우스 4번 버튼의 브라우저 뒤로가기(`popstate` 가드) 완벽 차단.

### 3-4. 상세 모달 & ‘게이밍 기어 특화 인간 증명(Human Proof-of-Work)’ 어뷰징 방지 시스템 (`src/components/specs/SpecDetailModal.tsx`, `src/lib/spec-verification.ts`, `src/components/specs/TesterDeviceBridge.tsx`)
- **기획 의도:** 도감의 실측 테스트 연동은 하드웨어 수치 과시용이 아니라, 매크로나 단순 클릭 연타를 통한 별점·투표 조작을 막는 **인간 증명(Human Proof-of-Work) 보안 게이트**로 활용.
- **4대 어뷰징 방지 선별 로직:**
  1. **무결점 실측 통과 게이트:**
     - 키보드 스위치: **`50회 이상` 타건 완료 + `채터링 감지 0회(무결점)`**
     - 마우스: **`1,500개 이상` 이동 샘플 수집 + `Peak 800Hz 이상` 도달 + `30회 이상` 버튼 클릭 + `더블클릭 감지 0회(무결점)`**
  2. **불량 수치 등록 차단:** 채터링이나 더블클릭이 1회라도 발생하면 인증 저장 버튼이 잠기며 `[초기화 후 재측정]` 안내 노출.
  3. **기기당 1인 1회 제한 (`verified_votes_[deviceId]`):** 재투표 시 총 표본 수가 늘어나지 않고 기존 본인 투표값만 수정(Overwrite)되며, 내 기록 우측 끝의 **휴지통 삭제 버튼** 클릭 시 즉시 삭제 및 평점·표본 수 원상 복구.
  4. **최소 표본 임계치 (5표 이상):** 참여 표본이 `5명 미만`일 때는 대표 성향 배지를 숨기고 `표본 수집 중 (현재 N/5명 참여)`로 표시하여 소수 표본에 의한 성향 왜곡 방지.
- **UI 정렬 디테일:**
  - 모달 하단의 중복 테스터 이동 버튼을 제거하고 실측 게이트 영역의 버튼으로 단일화.
  - 모든 인증 배지 문구를 **`⚡ 실측 인증`** 네 글자로 통일하고, 내 기록 표시 배지(`MY`)를 **`[⚡ 실측 인증] [MY]`** 순서로 배치하여 좌측 시작 열을 일직선으로 맞춤.
  - 우측 끝 삭제(휴지통) 버튼(`h-5 w-5`)이 없는 일반 유저 로그 행에도 동일한 `h-5 w-5` 빈 스페이서를 두어 `성향 / ★ 별점 / 날짜`의 수직 열 정렬을 완벽히 유지.
