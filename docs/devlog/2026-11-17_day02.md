## 1. 원격 검수 환경 구축 및 스펙 도감·인증 시스템 정교화

### 1-1. 외부 원격 접속(Cloudflare Tunnel) 및 Cross-Origin 허용 (`next.config.ts`)
- 외부 환경에서도 로컬 개발 서버(`localhost:3000`)의 UI와 인터랙션을 실시간 검수할 수 있도록 `Cloudflare.cloudflared` Quick Tunnel 연동.
- Next.js 16의 개발 서버 Cross-Origin 스크립트 차단 정책으로 인해 외부 터널 도메인(`*.trycloudflare.com`) 접속 시 정적 HTML만 로드되던 현상을 해결하기 위해 `next.config.ts`에 `allowedDevOrigins: ["*.trycloudflare.com"]` 설정 추가.

### 1-2. 스펙 도감 좌측 필터 헤더 줄바꿈 보정 (`src/components/specs/SpecsCatalog.tsx`)
- 스위치 필터 내부에 세로 스크롤바와 활성 필터 개수 배지가 동시에 나타날 때 상단 제목(`스위치 정형 필터`)이 두 줄로 밀리던 문제를 해결하기 위해, 제목을 **`스위치 필터` / `마우스 필터`**로 간결화하고 `whitespace-nowrap` 적용.

### 1-3. ‘실측 인증 / 실측러’ 워딩 및 과잉 배지 전면 정리 (`src/lib/spec-verification.ts`, `src/components/specs/TesterDeviceBridge.tsx`, `src/components/specs/SpecDetailModal.tsx`, `src/components/specs/SpecCompareModal.tsx`)
- **배경 및 문제의식:** 브라우저 테스터의 본래 목적은 **매크로·어뷰징 차단(실제 하드웨어 입력 확인)**이지 특정 스위치/마우스의 물리 스펙(gf, mm)을 계측하는 것이 아님에도, ‘실측 인증’·‘실측러’라는 표현과 제품명 표기가 붙어 있어 ‘제품 스펙을 직접 계측했다’는 오해와 시각적 피로도를 유발함.
- **개선 내용:**
  - 테스터 상단 브릿지 바(`TesterDeviceBridge.tsx`)에서 특정 모델명 표기를 제거하고 **`테스트 인증 모드`**로 명칭을 변경.
  - 키보드 테스터 1회 통과 시 모든 스위치 도감 평가가 열리고, 마우스 테스터 1회 통과 시 모든 마우스 도감 평가가 열리도록 글로벌 테스트 인증(`verified_proof_global_switch`, `verified_proof_global_mouse`) 통합.
  - 도감 상세 모달(`SpecDetailModal.tsx`), 1:1 비교 모달(`SpecCompareModal.tsx`), 상단 GNB, 커뮤니티 전역에서 노란색 `⚡ 실측 인증` / `⚡ 실측러` 배지를 모두 제거하고 내 기록에만 깔끔한 **`MY`** 배지를 유지.
  - 도감 미인증 안내 버튼 문구를 **`테스트하러 가기`**로 간결화하고, 섹션 타이틀을 `2. 유저 체감 지표 집계`, `3. 유저 체감 평가 기록`, 비교표 항목을 `유저 평점`으로 정리.

## 2. Phase 2-B — KEYNIVERSE 공식 커뮤니티 구축 (`src/components/community/*`)

### 2-1. 커뮤니티 카테고리 체계 및 데이터 스키마 (`src/types/community.ts`, `src/data/community-data.ts`, `src/lib/community-store.ts`)
- **4대 말머리(Category) 구성:**
  - 전체 탭 명칭: **`[전체]` · `[자유 게시판]` · `[빌드/셋업]` · `[투표]` · `[특가/드랍]`**
  - 목록 행 좌측 배지는 가독성과 제목 공간 확보를 위해 **2글자 축약형(`[자유]`, `[빌드]`, `[투표]`, `[특가]`, `[AD]`, 고정 폭 `w-[48px]`)**으로 통일.
- **상태 영속화(`localStorage` + `useSyncExternalStore`):**
  - 초기 리얼 더미 게시글 12종과 사용자가 새로 작성/삭제한 게시글, 추천 토글, 실시간 양자택일 투표, 특가 진행중/종료 상태 변경, 댓글 등록/삭제, 조회수 증가를 `keyniverse_community_state_v1` 스토리지에 동기화.

### 2-2. 고밀도 터미널 피드 & 반응형 레이아웃 (`src/components/community/CommunityBoard.tsx`)
- **상단 헤더 간결화:**
  - 타이틀을 **`KEYNIVERSE 공식 커뮤니티`**, 설명문을 **`여러분의 생각을 자유롭게 나누는 공간입니다.`**로 변경하고 우상단 요약 칩 제거.
- **카테고리 탭 바 1줄 고정 (`flex-nowrap overflow-x-auto`):**
  - 화면 폭이 좁아져도 게시판 탭이 두 줄로 꺾이지 않고 한 줄 가로 스크롤로 유지되도록 고정.
- **글 목록 테이블 디자인 & 정렬 디테일:**
  - **일반 글 볼드 해제 (`font-normal`):** 광고 행을 제외한 모든 일반 게시글 행의 말머리·제목·댓글수·추천수에서 볼드 속성을 제거해 눈의 피로도를 낮추고 차분한 리스트 가독성 확보.
  - **제목 옆 댓글 수 표시:** 제목 오른쪽에自动 태그 장비 칩을 숨겨 온전히 제목만 길게 보이도록 하고, 댓글이 있는 글은 제목 바로 우측에 세이지 그린 포인트로 **`[2]`**처럼 댓글 수 표기.
  - **칼럼 정렬 보정 (`780px` 이상):** `분류`·`제목`은 좌측 정렬, `작성자`(`w-[96px] pr-2`)는 우측 정렬, 그리고 한글 헤더와 숫자 폭 차이로 인해 중심축이 어긋나 보이던 **`작성일`(`w-[64px]`) · `조회수`(`w-[60px]`) · `추천수`(`w-[56px]`)는 헤더와 데이터 모두 `text-center`(중앙 정렬)**로 통일(추천수의 삼각형 `▲` 기호 제거).
  - **좁은 화면(`780px` 미만) 2단 반응형 전환:** 가로 폭이 `780px` 미만으로 내려가면 상단 칼럼 헤더를 숨기고, 1번째 줄에 `[분류] + 제목 + [댓글수]`가 전체 가로 폭을 쓰도록 한 뒤 2번째 줄 우측 하단에 **`작성자 | 작성일 | 조회 : N | 추천 : N`** 형태로 모아 표시.
- **하단 컨트롤 영역:**
  - 게시글 목록 바로 아래 우측에 **`[게시글 작성]`** 버튼을 배치하고, 그 아래 박스에 **검색창 + `[최신순 / 추천순]` 정렬**과 **페이지 표시기(10개 단위 페이지네이션: `< 이전`, `1`, `2`, `다음 >`)**를 상하로 배치.

### 2-3. 디자인을 해치지 않는 네이티브 AD 배너 슬롯 2종 & 우측 사이드바
- **인피드(In-Feed) 스폰서 행:** 게시글 리스트 최상단 1번째 줄에 `#1D211E` 배경과 우드 샌드(`#D4A373`) 테두리의 **`[AD]`** 배지, 볼드 처리된 스폰서 제목, 우측 끝 `[공식 스토어 · 310원/개 ↗]` 단가 링크 배치.
- **우측 Sticky 사이드바 (`w-[320px]`):**
  1. **`인기글 TOP 5`:** 현재 추천수 기준 상위 5개 게시글 랭킹 표시 및 클릭 시 해당 게시글로 즉시 이동.
  2. **`금주의 핫 VS 매치업`:** 최다 참여 투표 게시글의 실시간 득표율(`#6B9080` vs `#D4A373` 2-톤 매트 바) 미리보기.
  3. **`SPONSORED AD` 다크 매트 스펙 카드:** 스위치 단면 도트 그래픽과 핵심 스펙 요약, 공제 단가(`320원/개 · 11.24 마감`)를 담은 네이티브 스펙 카드형 배너.
- **원화 단위 표기 통일 (`원` / `원/개`):** 영문 고정폭 폰트(`JetBrains Mono`)에 `₩` 글리프가 없어 시스템 폰트로 폴백되면서 숫자보다 크고 굵게 보이던 현상을 해결하기 위해 모든 가격 표기를 **`원` / `원/개`**로 통일.

### 2-4. 보안 특화 Google 단일 로그인 시스템 (`src/lib/auth-store.ts`, `src/components/auth/AuthModal.tsx`, `src/components/layout/TopNav.tsx`)
- 향후 Supabase Google OAuth와 1:1로 직결할 수 있도록 아이디/비밀번호 입력란이 전혀 없는 **Google 단일 인증 모달(`AuthModal.tsx`)** 구현.
- 비로그인 상태에서 `[Google 로그인]`, `[게시글 작성]`, `[추천]`, `[투표]`, `[댓글 등록]` 클릭 시 호출.
- 상단 GNB(`TopNav.tsx`)의 반응형 전환 기준점을 `md(768px)`에서 **`lg(1024px)`**로 상향하고 중간 구분선을 제거하여, 창 폭을 줄여도 우측 로그인/로그아웃 버튼이 창 밖으로 밀려 나가지 않도록 해결.

### 2-5. 모달 제거 & 페이지 전환형 상세/글쓰기 뷰 + 리치 에디터 & 이미지 압축 첨부 (`src/components/community/PostDetailModal.tsx`, `src/components/community/PostWriteModal.tsx`)
- **모달 → 페이지 전환 방식 개편 (`/?post=ID`, `/?mode=write`):**
  - 답답한 팝업 모달을 제거하고, 우측 사이드바는 고정한 채 좌측 70% 메인 영역이 **게시글 상세 뷰** 또는 **글쓰기 뷰**로 전환되도록 개편 (브라우저 뒤로가기/앞으로가기 완벽 호환).
  - **상세 뷰 하단 전체 글 목록 연속 배치:** 게시글 댓글 바로 아래에 전체 글 목록과 페이지네이션이 이어서 보이도록 구성하여 목록으로 돌아가지 않고도 연속 탐색 가능.
- **게시글 상세 뷰 (`PostDetailModal.tsx`):**
  - 상단 메타 행은 좌측에 `작성자`(`MY`), 우측에 중복을 뺀 `작성일 · 조회수`(`삭제`)만 깔끔하게 배치.
  - 본문 외곽의 불필요한 라운드 테두리 박스를 제거하고 **`min-h-[380px]`**의 시원한 본문 영역을 최상단에 둔 뒤, **본문 아래쪽에 `[투표]` 매치업 위젯, `[빌드/셋업]` 컴팩트 빌드 스펙 요약(`w-fit`), `[자유 게시판]` 태그 장비 칩(`w-fit`)**이 오도록 상하 순서와 가로 폭 최적화.
- **리치 텍스트 에디터 & 이미지 전용 압축 첨부 (`PostWriteModal.tsx`):**
  - 모든 카테고리에서 **말머리 선택 → 제목 → 상세 본문 내용 → 하단 부가 항목(투표 매치업 / 도감 장비 태그 / 빌드·특가 정보)** 순으로 입력 흐름 통일.
  - **상단 서식 툴바:** 글자 크기(작게/기본/크게/제목), **굵게(B)**, *기울임(I)*, <u>밑줄(U)</u>, ~~취소선(S)~~, 테마 포인트 컬러 4종(`#E4E6E1`, `#6B9080`, `#D4A373`, `#E06C75`), 글머리 기호 리스트, 구분선 삽입 지원.
  - **본문 편집창 규격:** `min-h-[380px] max-h-[600px] overflow-y-auto`를 적용해 넉넉한 기본 높이를 제공하면서 긴 글 작성 시 내부 스크롤바가 동작하도록 구현.
  - **이미지 첨부 및 서버 과부하 방지 자동 압축:** `JPG / PNG / WebP / GIF` 이미지만 허용(게시글당 최대 5장, 장당 5MB 제한)하며, 파일 선택·드래그&드롭·클립보드 붙여넣기(`Ctrl+V`) 시 브라우저 `<canvas>`를 통해 **최대 가로 `1200px` WebP(품질 82%)로 자동 리사이징·압축**하여 본문 커서 위치에 즉시 삽입.
