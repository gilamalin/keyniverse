## 1. 사이트 공용 푸터(`<Footer />`) 및 통합 약관·제휴 페이지(`/policy`) 구축

### 1-1. 전역 공용 푸터 (`src/components/layout/Footer.tsx`, `src/app/layout.tsx`)
- `RootLayout`을 `min-h-full flex flex-col` 구조로 구성하고 `<main className="flex-1">` 하단에 전 페이지 공용 `<Footer />`를 배치하여 게시글이 적은 화면에서도 푸터가 항상 화면 최하단에 안정적으로 위치하도록 설계.
- **좌측 영역:** 브랜드 로고(`KEYNIVERSE`), 슬로건(**`키보드·마우스 하드웨어 커뮤니티`**), 카피라이트(`© 2026 KEYNIVERSE. All rights reserved.`) 배치.
- **우측 영역:** 상단 GNB와 중복되는 페이지 이동 링크를 제거하고, **`이용약관 · 개인정보처리방침 · 광고/제휴 문의`** 3대 필수 정책 링크만 배치하되 세 항목 모두 동일한 강조 폰트 색상(`font-semibold text-[#E4E6E1]/85 hover:text-[#E4E6E1]`)으로 통일.

### 1-2. 통합 정책 & 파트너십 페이지 (`src/app/policy/page.tsx`, `src/components/layout/PolicyViewer.tsx`)
- URL 쿼리(`?tab=terms | privacy | partnership`)와 연동되는 단일 통합 페이지(`/policy`) 구축:
  1. **`이용약관 (?tab=terms)`:** 커뮤니티 게시물 운영 기준(비방·바이럴·어뷰징 금지) 및 웹 테스트 계측 수치·스펙 도감 제원의 면책 조항 명시.
  2. **`개인정보처리방침 (?tab=privacy)`:** 자체 비밀번호 미수집 원칙(Google OAuth 2.0 단일 인증), 최소 식별 정보(UID, 이메일, 닉네임) 수집 목적 및 `localStorage` 활용 안내 명시.
  3. **`광고/제휴 문의 (?tab=partnership)`:** 커뮤니티 인피드 `[AD]` 구좌 및 우측 사이드바 스펙 카드 구좌 안내, 신규 장비 스펙 도감(`/specs`) DB 등재 요청 안내 및 공식 제휴 이메일(`partner@keyniverse.kr`) 원클릭 복사 기능 제공.

## 2. 공지사항(`[공지사항]`) 탭 및 게시판별 이용수칙 최상단 고정 로직

### 2-1. 게시판별 타겟팅 공지(`noticeScope`) 아키텍처 (`src/types/community.ts`, `src/data/community-data.ts`, `src/components/community/CommunityBoard.tsx`)
- 대형 커뮤니티(네이버 카페, 퀘이사존, 펨코 등)의 공지 노출 방식을 분석하여 **‘전체 공지 모아보기 탭 + 각 게시판별 맞춤 공지 1건 최상단 고정’** 하이브리드 구조 채택.
- `CommunityPost` 스키마에 `noticeScope?: "all" | "diagnosis" | "build" | "vs" | "deal"` 필드를 추가하고 5종의 초기 공식 공지사항 데이터 구축:
  - `[전체]` 탭 → 통합 커뮤니티 이용수칙 및 에티켓 안내 최상단 고정
  - `[자유 게시판]` 탭 → 자유 게시판 이용수칙 최상단 고정
  - `[빌드/셋업]` 탭 → 빌드/셋업 구성 기입 및 사진 첨부 안내 최상단 고정
  - `[투표]` 탭 → 양자택일 매치업 생성 및 참여 규칙 최상단 고정
  - `[특가/드랍]` 탭 → 바이럴·레퍼럴 금지 및 품절 시 종료 전환 규정 최상단 고정
  - `[공지사항]` 탭 → 5건의 전체 공지사항을 한눈에 모아 열람 (일반 유저의 글쓰기에서는 `notice` 말머리 선택을 제외하여 관리자 영역과 분리)
- **공지사항 시각적 위계 차별화:**
  - 게시글 목록에서 바로 아래 `[AD]` 스폰서 행(`#E4E6E1` 기본색 볼드)과 공지사항 행이 비슷해 보이지 않도록, **`[공지]` 게시글의 제목 텍스트에 소프트 세이지 그린(`text-[#88B09E] group-hover:text-[#A3C9B8]`)과 볼드(`font-semibold`)**를 적용해 첫눈에 공식 공지임을 식별할 수 있도록 개선.

## 3. 검색 실행 방식 개편 및 기간 범위(Duration) 필터 + 중앙 달력 모달

### 3-1. 엔터(`Enter`) 및 `[검색]` 버튼 기반 검색 실행 (`src/components/community/CommunityBoard.tsx`)
- 글자를 한 자씩 입력할 때마다 리스트가 즉시 필터링되던 방식을 개선하여, 입력 중인 텍스트(`searchInput`)와 실제 적용된 검색어(`appliedSearchQuery`)를 분리.
- 사용자가 검색어를 완성한 뒤 **`Enter` 키를 누르거나 검색창 우측의 `[검색]` 버튼을 클릭했을 때** 검색이 실행되도록 변경.

### 3-2. 기간(Duration) 드롭다운 필터 & 화면 중앙 달력 다이얼로그 모달 (`src/components/community/CommunityBoard.tsx`)
- 하단 컨트롤 바의 `[최신순 / 추천순]` 버튼 바로 왼쪽에 기간 범위 드롭다운 메뉴 추가 (기본값: **`전체`**, 옵션: **`전체 · 1일 · 3일 · 7일 · 30일 · 90일 · 직접 설정`**).
- **`'직접 설정'` 클릭 시 화면 중앙 달력 모달 전환:**
  - 드롭다운에서 `'직접 설정'`을 선택하면 기존 드롭다운 메뉴는 즉시 닫히고, **화면 정중앙에 다크 매트 달력 다이얼로그 모달**이 단독으로 열리도록 구현.
  - 400px 이하의 좁은 모바일 화면에서도 달력이 화면 밖으로 밀려 나가거나 잘리는 현상을 100% 방지했으며, 모달 안에서 **연도(`2024년~2027년`) 및 월(`1월~12월`) 드롭다운**과 날짜 그리드를 통해 단일 날짜 또는 시작일~종료일 범위를 직관적으로 선택 가능.

## 4. 답글(대댓글) · 수정 · 삭제 확인 모달 · 외형 테러(도배) 방지 시스템

### 4-1. 댓글 `Enter` 등록 / `Shift + Enter` 줄바꿈 및 답글(대댓글) 1단계 들여쓰기 (`src/components/community/PostDetailModal.tsx`)
- **댓글 및 답글 입력 UX:** `<textarea>` 기반으로 **`Enter` 입력 시 즉시 등록**(한국어 IME 조합 중복 방지 포함), **`Shift + Enter` 입력 시 줄바꿈**이 작동하도록 구현하고 플레이스홀더를 **`(Enter : 등록 / Shift+Enter : 줄바꿈)`**으로 간결화.
- **대형 커뮤니티 표준 1단계 들여쓰기(`1-Depth Indent + @멘션`) 렌더링:**
  - 원댓글에 답글을 작성하면 1단계 들여쓰기(`pl-6 sm:pl-8 bg-[#131614]` + `↳` 아이콘)로 그룹화되어 표시.
  - 답글에 또 답글(대댓글)을 작성하더라도 화면 우측으로 계속 밀려나지 않고 동일한 1단계 들여쓰기 라인을 유지하면서 본문 앞머리에 **`@대상닉네임`** 배지가 자동으로 부착되도록 구현.

### 4-2. 본인 작성 게시글 · 댓글 · 답글 수정 및 삭제 확인(Confirm) 모달 (`src/lib/community-store.ts`, `src/components/community/PostDetailModal.tsx`, `src/components/community/PostWriteModal.tsx`)
- **게시글 수정 (`/?mode=write&edit=POST_ID`):** 본인 게시글 상세 뷰 상단에 **`[수정]`** 버튼을 추가하고, 클릭 시 기존 제목·본문(HTML 포함)·말머리·첨부 이미지·장비 태그·메타 정보가 그대로 채워진 에디터로 전환되어 수정 저장(`updateCommunityPost`) 가능.
- **댓글·답글 인라인 수정:** 본인 댓글 및 답글 우측의 연필 아이콘 클릭 시 인라인 수정 `<textarea>`로 즉시 전환되며, 수정된 게시글·댓글·답글에는 `(수정됨)` 표시 부착.
- **삭제 확인(Confirm) 안전장치:** 게시글 또는 댓글·답글의 `[삭제]` 클릭 시 실수로 즉시 삭제되지 않도록 다크 매트 스타일의 **삭제 확인 다이얼로그 모달**을 먼저 띄워 `[삭제 확인]`을 눌렀을 때만 삭제되도록 보호.

### 4-3. 댓글·답글 및 게시글 외형 테러(세로 줄바꿈 도배) 방지 규격 (`src/lib/community-store.ts`)
- **댓글 및 답글 도배 방지:**
  - 1개당 **최대 500자 · 최대 15줄** 작성 제한 및 등록 시 **연속 3줄 이상의 줄바꿈(`\n{3,}`)을 최대 2줄(빈 줄 1칸)로 자동 압축**.
  - **5줄 초과 댓글 자동 접기:** 5줄을 초과하는 댓글·답글은 처음 5줄까지만 표시하고 하단에 **`[더보기 ▾]` / `[접기 ▴]`** 토글 버튼 노출.
- **게시글 도배 방지:**
  - **제목:** 최대 **80자** 제한 + 연속 공백 단일화.
  - **본문:** 대형 커뮤니티(MySQL `TEXT` 컬럼 64KB 규격) 표준에 맞춰 텍스트·글자 서식·굵기·색상·줄바꿈 태그·이미지 링크 태그를 모두 포함한 **HTML 기준 최대 `65,535자`** 및 **최대 `200줄`** 상한선 적용 (연속 3줄 이상 빈 블록 자동 압축 포함).

## 5. 닉네임 2~6자 규격화 및 전역 UI/UX 폴리싱

1. **닉네임 2~6자 제한 및 특수기호·공백 금지 (`src/lib/auth-store.ts`, `src/components/auth/AuthModal.tsx`, `src/data/community-data.ts`):**
   - 한글(완성형 `가-힣`), 영문(`a-zA-Z`), 숫자(`0-9`)만 허용하고 공백·특수기호·단독 자모를 금지하는 **2~6자 닉네임 검증 로직(`validateNickname`)** 적용.
   - 게시판 목록 작성자 컬럼 폭을 `w-[116px]`로 확보하고 초기 더미 데이터의 모든 작성자명을 6자 이하로 정리하여, 한글·영문·숫자를 어떻게 조합하거나 `[MY]` 배지가 붙더라도 `(...)` 말줄임표로 잘리지 않도록 완비.
2. **신규 게시물 초기 추천 수 `0` 시작 & 빌드 스펙 요약 장비명 간소화:**
   - 새 게시글 등록 시 초기 추천 수가 `0`부터 시작하도록 수정하고, `[빌드/셋업]` 상세 뷰의 '빌드 스펙 요약' 박스 내 장비 링크 칩에 복잡한 부가 스펙 대신 **제품명(`BSUN 로즈우드`)만** 깔끔하게 표시.
3. **게시글 작성 페이지(`PostWriteModal.tsx`) UI 정돈:**
   - 상단 타이틀을 **`게시글 작성`**(수정 시 **`게시글 수정`**)으로 간소화하고 우측 작성자 배지 제거.
   - 섹션 라벨을 **`게시판 선택`**, **`게시글 제목`**, **`본문 내용`**으로 통일하고, 모바일에서 두 줄로 꺾이지 않도록 에디터 우상단에는 **`이미지 0/5장`**만 심플하게 표시.
   - `[자유 게시판]`과 `[특가/드랍]` 작성 시에는 하단 '도감 장비 태그 선택기' 박스를 숨기고 **`[빌드/셋업]` 작성 시에만 노출**되도록 정리.
4. **우측 사이드바 및 모바일 헤더 간결화:**
   - 우측 사이드바 `인기글 TOP 5`의 `'추천수 기준'` 문구와 `금주의 핫 VS 매치업`의 `'총 N명 참여'` 문구를 제거해 숫자 중심의 직관적 레이아웃 완성.
   - 모바일/좁은 화면(`lg:hidden`)에서 햄버거 메뉴 아이콘 좌측에 중복 표시되던 현재 페이지명 배지 제거.
5. **`'키보드 테스터' · '마우스 테스터' · '테스터'` → `'키보드 테스트' · '마우스 테스트' · '테스트'` 명칭 일원화:**
   - 상단 GNB, 페이지 메타데이터, 키보드/마우스 테스트 페이지 메인 `<h1>` 및 섹션 타이틀, 도감 상세 모달, 이용약관 내 모든 `'테스터'` 문구를 **`'테스트'`**로 통일.
