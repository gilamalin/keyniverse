## 3. 실제 Google OAuth 로그인 & 어뷰징 방지 계정 라이프사이클

1. **Google OAuth + 최초 닉네임 설정 (`src/lib/auth-store.ts`, `src/components/auth/NicknameSetupModal.tsx`):**
   - Google Cloud Console OAuth 2.0 클라이언트 및 Supabase Google Provider 연결.
   - 신규 가입 시 `handle_new_user()` 트리거가 `profiles` 행 생성 + 환영 포인트 `+50 P`를 자동 기록하며, `profiles.nickname IS NULL`인 최초 로그인 유저에게는 **닉네임 설정 모달**을 자동 팝업.
2. **닉네임 변경 30일 쿨타임 & 예약어 차단 (`supabase/nickname_cooldown_migration.sql`):**
   - `profiles.nickname_changed_at` 컬럼과 `enforce_nickname_cooldown()` 트리거로 최초 가입 직후 오타 수정용 1회 변경만 허용하고, 이후 변경부터 **30일 쿨타임** 적용 및 `posts`·`comments` 작성자명 자동 동기화.
   - `validateNickname()`에 사칭 방지 예약어(`관리자`, `운영자`, `admin`, `키니버스`, `공지` 등) 및 기본 비속어 차단 경고 적용.
3. **회원 탈퇴 + 30일 재가입 쿨타임 (`supabase/withdraw_migration.sql`):**
   - `delete_own_account()` RPC 실행 시 개인정보(`auth.users`, `profiles`)는 즉시 파기하되, 탈퇴→재가입 포인트/투표/신고 어뷰징을 막기 위해 이메일의 단방향 **SHA-256 해시**만 `withdrawn_hashes`에 30일간 보관.
   - 기존 작성 글·댓글은 `탈퇴한 사용자`로 익명화해 토론 흐름 및 신고 증거 보존.
   - 30일 이내 재가입 시도 시 `/?auth_error=withdrawn_cooldown`을 감지해 로그인 모달에 **`"탈퇴 후 30일간 같은 계정으로 재가입할 수 없습니다."`** 안내 문구 자동 표시.

## 7. 배포 후 기능 보강 & 실사용 UI 시각 위계 고도화

### 7-1. 게시글 조회수 DB 영구 저장 & 세션당 1회 카운트 (`supabase/post_views_migration.sql`, `src/lib/community-store.ts`)
- 기존 로컬 스토리지(`localStorage`)에만 누적되던 조회수를 Supabase `posts.views` 컬럼에 영구 저장되도록 **`increment_post_view(target_post_id uuid)`** `SECURITY DEFINER` RPC 함수 작성(`anon`, `authenticated` 모두 호출 가능).
- 새로고침 연타로 인한 조회수 복사(어뷰징)를 방지하기 위해 `sessionStorage` 기반 `markPostViewedInSession()`을 추가하여 **브라우저 세션당 게시글별 1회만 카운트**되도록 제한하고, DB 게시글에서 `extraViews`가 이중 가산되지 않도록 정비.

### 7-2. PC·모바일 시각 위계 개선 (`CommunityBoard.tsx`, `TopNav.tsx`, `PostDetailModal.tsx`, 전 페이지 헤더)
- **상단 대제목 헤더 조건부 숨김:** 게시글 상세(`selectedPost`) 및 글쓰기/수정(`isWriteMode`) 화면에서는 상단 `KEYNIVERSE 공식 커뮤니티` 대제목 배너를 PC·모바일 모두 숨겨, 짧은 글에서도 제목과 본문에 즉시 시선이 모이도록 개선(목록 화면에서는 유지).
- **명도·크기 위계 분리:**
  - 상단 로고 `KEYNIVERSE`: `#E4E6E1` → **`#C9CFCB`**(호버 시 `#E4E6E1`)
  - 전 페이지 대제목(`h1`): `#E4E6E1` → **`#D5DBD6`**, 모바일 크기 `text-2xl` → `text-xl`(`sm:text-3xl`)
  - 게시글 상세 제목(`h2`): `#E4E6E1` → **`#F4F6F2`**로 명도를 높여 최상위 시선 포인트로 강조

### 7-3. 분류 배지 무채색 통일 & 닉네임·`MY` 배지 톤 정리 (`CommunityBoard.tsx`, `PostDetailModal.tsx`, `TopNav.tsx`)
- **분류 배지 통일:** 일반 분류(`[자유]`, `[빌드]`, `[투표]`, `[특가]`) 배지를 저채도 무채색(`border-[#282D2A] bg-[#151816] text-[#8F9691]`)으로 통일하고, 상단 고정 행인 `[공지]`(세이지)와 `[AD]`(앰버)만 유채색 포인트를 유지해 글 제목 스캔 가독성 향상.
- **닉네임 및 `MY` 배지 톤 다운:** 게시글 상세 작성자 닉네임(`#B5BCB7`), 헤더 우상단 내 닉네임(`#B8BFBA`)으로 차분하게 눌러 본문과의 경쟁을 줄이고, 목록·상세의 `MY` 배지를 솔리드 채우기에서 아웃라인 틴트(`border-[#6B9080]/40 bg-[#6B9080]/10 text-[#6B9080]`)로 변경.
