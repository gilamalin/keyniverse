  - `DOMParser` 기반 화이트리스트 정제기(`sanitizePostHtmlContent`) 도입으로 저장·조회·렌더링 전 구간에서 위험 태그·이벤트 핸들러(`on*`)·위험 스킴·오버레이 CSS를 원천 차단.
  - 기존 공지사항 및 에디터 서식(`font size/color`, Safari `rgb(...)`, `h3`, `ul/li`, `hr`, 첨부 이미지 `data-attachment-id`)은 100% 보존하고, `onPaste`는 위험 마크업이 감지될 때만 정제 삽입해 일반 복붙과 `Ctrl+Z` 실행 취소를 유지.

  - `JSON.stringify(jsonLd).replace(/</g, "\\u003c")` 적용.
- **`H-1` 특가 스토어 URL 스킴 검증:**
  - `sanitizeExternalHttpUrl` 헬퍼로 `http://`·`https://` 외 비정상 프로토콜의 저장 및 `<a>` 렌더링 차단.
- **`H-2` · `H-3` Supabase 통합 보안 마이그레이션 ([security_audit_v2_migration.sql](file:///c:/00_Project/02_Keyniverse/supabase/security_audit_v2_migration.sql)):**
  - `SECURITY INVOKER` + `current_user in ('authenticated', 'anon') and pg_trigger_depth() <= 1` 조건으로 내부 `SECURITY DEFINER` 트리거·RPC(가입 `+50P`, 포인트 합산, 추천수 동기화, 조회수 증가, 닉네임 동기화, 탈퇴 익명화)와 충돌 없이 클라이언트 직접 컬럼 변조만 정확히 차단.
  - `profiles` 민감 컬럼(`points`, `email`, `role`, `banned_until`, `nickname_changed_at` 임의 수정) 보호, `point_logs` 클라이언트 적립폭(`3, 5, 10`) 제한, `posts`·`comments` 추천수·조회수·작성자 닉네임 위조 차단 트리거 구축.
  - 활동 정지(`is_banned()`) 계정의 기존 댓글 수정·스펙 평가·신고·추천·투표·이미지 업로드 차단 및 `community-images` 버킷 `5MB` 용량·이미지 MIME 4종·본인 UID 폴더 경로 강제.

## 3. 커뮤니티 UX 개선 & 라이브 테스트 마감 (`b3875f1`, `fc0591b`, `4290175`)
- **게시판별 `[글쓰기]` 기본 카테고리 자동 매칭:** `빌드/셋업`·`투표`·`특가/드랍`·`자유 게시판`에서 글쓰기 진입 시 해당 게시판 자동 선택(`공지사항` 탭은 관리자만 `공지사항`, 일반 계정은 `자유 게시판` 매칭 / 사이드바 `투표 만들기 →`도 `투표` 자동 선택).
- **정지 계정 프론트 사전 차단 + 자동 롤백:** [PostDetailModal.tsx](file:///c:/00_Project/02_Keyniverse/src/components/community/PostDetailModal.tsx), [SpecDetailModal.tsx](file:///c:/00_Project/02_Keyniverse/src/components/specs/SpecDetailModal.tsx)에서 정지 계정 클릭 시 로컬 카운트를 올리지 않고 `"활동 정지 기간에는 이용할 수 없습니다."` 안내 표시 + DB 에러 시 자동 원복.
- **투표 후보 하이브리드 입력창(방안 C) & 레이아웃 보정 ([PostWriteModal.tsx](file:///c:/00_Project/02_Keyniverse/src/components/community/PostWriteModal.tsx)):**
  - 201개짜리 `<select>`를 도감 검색 자동완성(`스펙 연동` → `[스펙 ↗]` 자동 활성화) + 자유 텍스트(`직접 입력`) 통합 입력창으로 교체하고 검색 필터에도 후보명을 포함.
  - 자동완성 목록을 입력창 위쪽 플로팅(`absolute inset-x-0 bottom-full z-30 mb-1.5`)으로 띄워 목록 길이 변화에 따른 화면 튐(0px)과 모바일 가상 키보드 가림 방지(`fc0591b`).
  - `OPTION A/B` 라벨 행 높이 고정(`h-6`) 및 `스펙 연동`/`직접 입력` 칩을 `h-5 font-sans text-[11px] leading-none`으로 통일해 입력칸 밀림 및 한글 정렬 어긋남 해결(`4290175`).
